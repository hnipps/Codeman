# Architecture

The promises this repository already keeps are written in `docs/architecture-invariants.md`. The short form is in `CLAUDE.md` and `src/web/CLAUDE.md`. Tests under `test/` pin the rules that have a test.

This file adds none of those promises again, and it carries no numbered ids. Edit the architecture document in the same change as the code when one of those rules changes.

A new promise that is still moving, and that the architecture document does not already state, goes in its own file in this directory with `Status: Draft`.
